# 📚 Revista de Investigación Científica

Este proyecto implementa un sitio web académico para la **Revista de Investigación de Artículos Científicos**, siguiendo las indicaciones del documento *INDICACIONES PARA PAGINA WEB.docx*.  

Incluye:
- Estructura HTML5 (`index.html`)
- Estilos CSS3 responsivos (`style.css`)
- Interactividad básica con JavaScript (`script.js`)
- Recursos multimedia (logo, portada, galería de fotos)
- Publicación principal en PDF: *REVISTA CRÍTICA Y ACCIONES*

## ⚙️ Instalación local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/usuario/ProyectoWebRevista.git
2. Ingresa a la carpeta:

    bash
    cd ProyectoWebRevista

3. Abre el proyecto en Visual Studio Code.
4. Ejecuta el archivo index.html en tu navegador (clic derecho → Open with Live Server si tienes la extensión instalada).

🌐 Publicación en GitHub Pages
1. Sube tu proyecto a un repositorio en GitHub.
2. Ve a la pestaña Settings del repositorio.
3. En el menú lateral, selecciona Pages.
4. En Source, elige la rama main y la carpeta raíz (/root).
5. Guarda los cambios.
6. GitHub generará una URL pública, por ejemplo:

Código
https://usuario.github.io/ProyectoWebRevista

Accede a esa URL para visualizar tu revista en línea.
